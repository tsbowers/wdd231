NP Membership Benefits

The NP Membership is designed for nonprofit organizations and has no membership fee.

  • Chamber directory listing
  • Community networking opportunities
  • Access to selected chamber events

Bronze Membership Benefits

The Bronze Membership is a good starting level for small businesses.

  • Chamber directory listing
  • Newsletter recognition
  • Basic event discounts

Silver Membership Benefits

The Silver Membership includes additional promotional opportunities.

  • All Bronze benefits
  • Training event discounts
  • Social media mentions
  • Priority event registration

Gold Membership Benefits

The Gold Membership provides the highest level of chamber visibility.

  • All Silver benefits
  • Homepage spotlight opportunities
  • Premium advertising options
  • VIP event discounts
